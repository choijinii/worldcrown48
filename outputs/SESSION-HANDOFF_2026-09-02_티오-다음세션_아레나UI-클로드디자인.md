## 2. 이번 세션의 일: Claude Design에서 아레나 UI 만들기 (대표와 함께)
역할: 대표가 Claude Design에서 시각 층을 만들고, 티오는 **화면별 요구·수치 규칙을 프롬프트로 공급 + 산출물이 킥 수치와 맞는지 대조**한다. 순서는 ARENA-1 §C의 5화면:
- C1 VS 스플릿 무대(상태 5종: idle/focusL/focusR/pickedL/loading) — 100vw/vh 50:50, 포커스 쪽 flex 1.5~2·scale 1.1·saturate 30→100%, 기본 정지 포스터(자동재생 없음), 모바일 상하 2탭(1탭=확대·재생, 2탭=확정 — 프로토타입에서 대표 최종 확정), 라운드/득표율/타이머 없음, 다크.
- C2 결승 3분할 · C3 라운드 전환(동심원·코너 라벨, 라운드명 유일 노출처) · C4 ★대관 연출(콘티 5컷+프로토타입, 7층 레이어, 2.5~3초, 탭 대기) · C5 첫 입장 팝업(얇게).
- 디자인 계약: worldcrown48-design 스킬(v2.3 Twilight Stadium) + Crown Gold 단일 포인트 + 축제의 언어. 여유 되면 ARENA-2 예습(화이트 대기실·전광판)도.
- 완료 시 **"Send to Claude Code" 핸드오프 번들** 수령 → 킥 §C 수치 대조(충돌 시 킥이 이김) → ARENA-1 v1.0 발행.

```
WorldCrown48(월크48) 아레나 매치 무대 리디자인. 디자인 시스템: Twilight Stadium v2.3 — 다크 네이비 배경, Crown Gold #FCD006 단일 포인트 색, Crimson #D7063A(우)·Turquoise #00A3B7(좌)는 상태색만, 순수 검정 금지, 한/영 동급 타이포.
아트보드 5장 (데스크톱 1440×900 기준 + 모바일 390×844 변형):
1) VS 스플릿 무대 — 화면 전체를 좌우 50:50으로 가르는 두 참가자 패널(유튜브 영상 정지 포스터), 중앙 VS 뱃지. 상태: 기본 / 왼쪽 포커스(왼쪽이 1.5~2배로 벌어지고 scale 1.1, 채도 100%, 오른쪽은 채도 30% 축소) / 픽 확정(골드 체크) / 로딩. 금지: 라운드 라벨, 득표율, 타이머, LIVE 뱃지.
2) 결승 3분할 — 같은 무대의 3분할 변형, 3인 중 1명 직접 선택, 카드 위 크라운 글리프.
3) 라운드 전환 — 전체화면, 동심원 링 + 코너 라벨 4개 + "ROUND OF 24" 큰 타이포 + 진행 바(2초). 라운드명은 이 화면에만.
4) 대관 연출(Crown Ceremony) 콘티 5컷 — 0.0초(결승 픽 직후) / 0.3초(탈락 2인 어두워지며 물러남) / 0.8초(크라운 하강, 뒤 광채) / 1.2초(반짝임+CROWNED 등장) / 정지 프레임(완성 화면, 탭 대기). CROWNED는 폰트, 모션은 위치·크기·회전·투명도만.
5) 첫 입장 안내 팝업 — 얇게: 환영 한 줄 + 데이터 안내 + 시작 버튼.
```
