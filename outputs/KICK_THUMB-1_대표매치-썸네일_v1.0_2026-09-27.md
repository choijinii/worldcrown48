## §0 한 줄 요약
대회 썸네일은 **대회 주인이 편집기에서 고른 "대표 매치" 엔트리 2개의 VS 장면 하나뿐**이다. 업로드 칸도, 자동 콜라주도, 순위 따라 바뀌는 모드도 없다. 2개를 골라야 게시할 수 있다. 칸마다 위치 조절 막대로 얼굴을 맞춘다.

## §3 화면 (디자인 정본 = 클로드 디자인, 원장 D-20 — 아래는 뼈대)
```
편집기 STEP 2 (48 그리드 위쪽) — 대표 매치 패널
┌ 대표 매치 (필수) ───────────────────────────────────┐
│ ┌──────────┬──────────┐  48개 중 2개를 누르세요        │
│ │  엔트리 A │  엔트리 B │  [A: 12번] [B: 31번] [바꾸기]  │
│ │   (얼굴)  VS  (얼굴)  │                              │
│ └──────────┴──────────┘                              │
│  A 위치 ━━━●━━━━   B 위치 ━━●━━━━━                     │
│  미리보기: [피치 카드] [아카이브 카드] [전광판]            │
└─────────────────────────────────────────────────┘
그리드 칸 → 누르면 A → 다른 칸 → B → 세 번째 누르면 A부터 교체
게시 버튼: A·B가 다 차기 전에는 잠김 + 이유 한 줄 표시
```
- 피치 카드 커버: 왼쪽 A · 가운데 **VS** 표식 · 오른쪽 B · 아래 딤 토큰 위에 대회 제목.
- **위치 조절 막대**: 칸마다 1개. 8:9 칸에 들어갈 부분을 옮긴다 — 가로 영상은 좌우, 세로 사진은 위아래(한 방향만 움직임). 값 0~100, 기본값 = 매치 무대 규칙. 막대를 움직이면 미리보기 3곳이 바로 바뀐다.
- 배너 자리(원장 D-21): 썸네일 자체에는 배너 없음. 편집기는 관리자 전용 화면이라 배너 자리 해당 없음. 피치 카드 목록 화면의 배너 자리는 기존 그대로(변경 없음).

## §4 게시 막기와 자동 대체 규칙
1. **게시 전**: A·B 둘 다 골라야 게시 버튼이 열린다. 편집 중에 고른 엔트리를 빼거나 바꾸면 그 칸이 비고, 다시 골라야 게시된다(자동 대체 없음).
2. **게시 후 고른 엔트리가 지워지면**: 그 칸에 **살아 있는 엔트리 중 앞 번호**가 자동으로 들어간다(기본 1번·2번. 1번·2번 중 하나가 지워진 경우면 그다음 번호). 빈 칸 금지. 위치 막대 값은 기본값으로 돌아간다.
3. **고른 엔트리가 지워지는 경우** (대표 질문 09-27 답):
   - ㉠ 권리자 요청(저작권·초상권)이나 신고로 대표가 관리자 화면에서 그 엔트리를 내릴 때
   - ㉡ 유저 대회(MVP1.5)에서 신고 3건/10건 절차로 엔트리가 내려갈 때
   - ㉢ 게시 후 편집기에서 엔트리를 교체할 때 — **이 기능이 지금 있는지는 Claude Code가 착수 때 코드로 확인**해 보고
   - ㉣ 원본 영상이 유튜브에서 삭제·비공개되어 엔트리는 남아 있는데 그림이 안 뜰 때 — **이것도 "지워진 것"으로 보고 ②와 같이 앞 번호로 대체한다(대표 원칙, 09-27 23:0x)**. 그림 불러오기 실패를 감지하면 화면에서 대체하고, 관리자 화면에 "대표 매치 그림 깨짐" 표시를 남겨 대표가 알 수 있게 한다(티오 보강 — 구현 방식은 Claude Code가 제안).

## §5 데이터 (additive — 기존 문서 무영향)
- Tournament 문서에 `thumbnailPair: { a: contestantId, b: contestantId, aPos: 0~100, bPos: 0~100 }` 추가.
- 기존 대회(필드 없음)는 규칙 §4-2와 같이 1번·2번 + 기본 위치로 표시(빈 칸 금지). 기존 대회를 억지로 채우는 백필은 하지 않는다 — 대표가 편집기에서 열어 고르면 된다.
- 쓰기 = 대회 주인(hostUid)만(기존 tournaments 규칙 그대로). 읽기 = 기존 규칙.
- 계측 후보: `thumbnail_pair_set`(편집기) — EVENT_SPEC 대조 후 확정.

## §6 지키는 규칙
- **파일로 합성·저장 금지**(법리) · 외부 이미지 금지(엔트리 썸네일만) · raw hex 금지(토큰) · 화면 문구 3언어 + **전후 비교 승인 게이트** · Round 라벨 금지(Round Scope Lock) · LIVE 뱃지 금지 · 전투 은유 금지("VS"는 기존 매치 무대 표식 그대로) · '표' 낱말 금지.
