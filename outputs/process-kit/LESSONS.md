# LESSONS — 실제로 겪은 것만

추측이나 일반론은 적지 않는다. **실제로 한 번이라도 당한 것**만 적는다.
킥이 끝날 때마다 한 줄씩 추가하고, 같은 걸 두 번 당하면 가드나 체크리스트로 승격시킨다.

---

## 운영

**맥북 잠자기가 실행 AI 응답을 끊는다.** 30분 넘는 작업은 `caffeinate -d`(macOS 터미널) 또는 잠자기 방지 설정. 작업물은 커밋되어 있으므로 "이어서 진행"이면 복구된다.

**Secrets 입력 프롬프트는 붙여넣어도 화면에 아무것도 안 보인다.** 한 번만 붙여넣고 Enter. 안 붙었나 싶어 두 번 붙이면 값이 망가진다.

**새 API 키는 새로 만든다.** 자동 생성된 기존 키(브라우저 키 등)에 제한을 걸면 라이브 서비스가 멈춘다. 새 키 + 용도 제한이 정답이다.

**CLI가 "Invalid project id" 류로 거부하면** 프로젝트 지정 플래그를 붙이거나(`--project <id>`) 한 번 연결(`use --add`)해 둔다. 툴이 고장 난 게 아니라 컨텍스트가 없는 것이다.

## CI · 배포

**프리뷰 CI의 "fail"이 코드 실패가 아닐 수 있다.** 프리뷰 URL 대기 시간 초과인 경우가 잦다. 로그를 먼저 읽고 재실행한다(`gh run rerun --failed`). 여러 워크플로가 **동시에** 같은 방식으로 죽었다면 코드가 아니라 그 커밋에 프리뷰 배포 자체가 없는 것이다.

**조건부 스킵이 걸린 워크플로는 0건 실행하고 초록불이 된다.** 의심스러운 green은 로그에서 실제 실행 건수를 확인한다.

**고정된 URL/SHA를 가리키는 테스트는 엉뚱한 코드를 테스트한다.** 통과해도 의미가 없고, 나중에 그 URL이 죽으면 그제야 드러난다.

## 가드 · 검증

**가드의 스캔 범위에서 도구 폴더를 제외한다.** 에이전트 워크트리(`.claude/` 등)는 리포 자신의 옛 사본이라, 훑으면 이미 고친 파일의 과거 버전이 위반으로 다시 잡힌다(로컬 159건 오탐 → CI와 결과가 갈림).

**예외(allowlist)는 파일+값 쌍으로 좁게 등록하고 사유를 반드시 적는다.** 파일 전체 면제는 무관한 새 위반까지 통과시킨다. **미사용 예외를 감지하는 기능이 가드에 있어야 한다** — 아무도 다시 확인하지 않은 예외가 조용히 사각지대를 넓힌다.

**정적 검토로 안 잡히는 회귀가 있다.** 값 대조·grep이 전부 통과했는데 실제 렌더에서만 드러나는 변화가 있었다(스코프 밖이라 무효화되던 선언이 살아나면서 없던 그림자가 생김). "결과 불변"을 주장하려면 **실제 실행 결과를 대조**해야 한다.

**킥의 규모 추정과 실측이 다른 건 흔하다**(117건 추정 → 211건 실측). "기준선 스냅샷 → 0으로" 방식이면 숫자가 얼마든 구조가 흡수한다. 추정이 틀렸다고 멈추지 않는다.

## 문서 · 소통

**문서에 있다고 적힌 라이브러리가 실제로는 없을 수 있다.** 실행 AI는 그 함정에 그대로 빠져 존재하지 않는 API로 코드를 쓴다. 프로젝트 헌법 문서에 **"없는 것" 경고 블록**을 두는 게 효과적이었다.

**설계 파트너 메모리는 실행 파트너에게 보이지 않는다.** 킥에 "메모리 X 참조"라고 쓰면 실행 파트너는 그 파일을 못 찾는다. 필요한 내용은 킥 본문에 인라인으로.

**프롬프트의 금지 규칙은 이웃 범주로 번진다.** "이 단어를 쓰지 마라"가 "그 계열 단어를 피하라"로 일반화되면서 보존해야 할 고유명사까지 바뀐 적이 있다. **보존 규칙을 먼저, 금지 범위는 좁게, 그리고 생성물 1건은 반드시 눈으로 확인**한다(존재 검증만 하는 테스트는 이걸 못 잡는다).

**결정은 바뀌었는데 규범 문서가 옛 원칙을 말하고 있는 상태가 가장 위험하다.** 코드는 최신인데 문서가 옛날이면 다음 세션이 문서를 믿고 오답한다. 발견하면 별도 킥으로 스윕한다.

**진단을 시작하기 전에 열린 이슈부터 검색한다.** 정답이 이미 이슈에 몇 주간 올라와 있었던 적이 있다 — 틀린 진단과 불필요한 배포로 이어졌다.

## 신뢰

**실행 AI가 스스로 저지른 실수를 스스로 찾아 고치고 보고하는 건 신뢰의 신호다.** 숨기지 않았다는 뜻이다. 반대로 "다 됐습니다"만 있고 숫자가 없는 보고는 다시 물어본다.

**실행 AI의 (권장) 표시는 지금까지 전부 정확했다.** 급할 땐 (권장)을 따라도 안전했다. 다만 그 판단의 근거를 PR에 남기게 한다.
