## §0 목적 / 완료 정의(DoD)

**목적**: <한 문장. "무엇을 왜">

**DoD**
- [ ] <무엇이 어떻게 되면 끝인가 — 체크 가능한 문장으로>
- [ ] <숫자로 판정되는 것을 하나는 넣는다: "위반 0건", "N건 green">
- [ ] 최종 보고에 "핸드오프와 달랐던 점"

> 실행 AI가 **"다 됐다"를 스스로 판정할 기준**이다. "잘 동작한다" 같은 문장은 판정 불가 — 명령어와 기대 출력으로 쓴다.

## §1 필독 컨텍스트 (인라인)

> 관련 결정·규칙·용어를 **본문에 직접** 옮겨 적는다. 설계 파트너 메모리 참조("[[memo-x]] 참조")는 실행 파트너에게 **보이지 않는다.**

- 리포 내 필독 문서: `CLAUDE.md` · <이 킥에 걸리는 규범 문서 경로>
- 확정된 결정: <날짜 · 무엇이 어떻게 정해졌는지>
- 용어: <이 킥에서 쓰는 단어의 정의. 기존 용어를 재정의하지 않는다>

## §2 규모 실측치

> 사전에 잡은 숫자(파일 수·건수)를 적는다. **"실측이 다르면 보고하되 계속"** 한 줄을 반드시 붙인다 — 추정과 실측은 거의 항상 다르고, 그때마다 멈추면 진도가 안 나간다.

대상 <N>파일 / <M>건 (실측 기준일 {{DATE}}). 실측이 다르면 보고하되 계속.

## §3 스코프 IN / OUT

| | 내용 |
|---|---|
| **IN** | <이번에 하는 것> |
| **OUT** | <절대 안 하는 것 — "리팩터링 유혹 금지" 같은 문장 포함> |
| **후속 킥** | <넘기는 것 + 왜 지금 아닌지> |

> 스코프 확장은 사후에 막을 수 없다. 여기서 미리 막는다.

## §4 RULE

> 위반 불가 원칙. 실행 AI가 판단이 갈릴 때 기준으로 삼는 줄이다. **"이걸 어기게 되면 STOP"** 이라는 뜻이기도 하다.

- **R1** <예: 시각 결과 불변 — 값의 이름만 바꾼다>
- **R2** <예: 추가만 허용. 기존 필드·경로 삭제 금지>
- **R3** <예: 숫자 하드코딩 금지 — 설정에서 읽는다>
- **R4** <예: API 키는 서버 전용. 클라이언트 번들·리포·로그에 절대 노출 금지>

## §5 Phase 분할

> 중간에 끊겨도(잠자기·API 오류) 이어받을 수 있게 나눈다. Phase 하나 = 커밋 하나가 기본.

- **A** <산출물 · 커밋 단위>
- **B** <…>
- **C** <…>
- **D** PR(4블록) → CI → 사람 검증 → 머지 → 배포

## §6 Auto-STOP 조건

> **프로세스의 심장.** "이 상황이면 반드시 멈추고 질문"을 나열한다. 실제로 발동한 5유형:
> ① 킥 문면과 실측이 충돌 ② RULE과 작업이 충돌 ③ 스코프 경계 판단 ④ 사람만 할 수 있는 일 ⑤ 추측으로 채워야 하는 빈칸
> 좋은 STOP은 **근거(코드 위치) + 선택지 2~3개 + (권장) 표시**를 함께 낸다.

- <킥 문면과 리포 실물이 다름> → STOP (근거 위치와 권장안을 함께)
- <RULE R1을 지키면 요구사항을 못 지키는 상황> → STOP (대안 2~3개)
- <스코프 경계에 걸리는 파일/케이스 발견> → STOP (포함·제외의 결과를 각각)
- <계정·키·로그인이 필요> → STOP (사람이 할 절차를 순서로)
- <문서에 없어 추측해야 하는 값> → **추측 금지.** STOP 또는 대조군으로 대체하고 보고

## §7 검증 하네스

> **기계 검증**과 **사람 검증**을 나눠 적는다. "됐다"를 숫자로 증명하는 게 기계 쪽 몫이다.

| | 무엇 | 통과 기준 |
|---|---|---|
| 기계 | `{{TEST_CMD}}` · `{{GUARD_CMD}}` · `{{BUILD_CMD}}` | 전부 green, 가드 위반 0건 |
| 기계 | <전용 하네스가 필요하면 여기 — 예: 결과 불변 대조> | 차이 0건 |
| 사람 | 프리뷰에서 <어느 화면의 무엇>을 본다 | <기대 상태> |
| 사람 | 프로덕션에서 <로그인 뒤 화면> 30초 확인 | <기대 상태> |

> 프리뷰에서 로그인이 안 되는 건 정상인 경우가 많다(인증 승인 도메인 미등록). 로그인 뒤 화면은 머지 후 프로덕션 확인으로 대체한다.
> 실행 AI가 **"여기를 중점으로 보라"** 고 지목한 지점(회귀가 났다가 롤백된 자리 등)을 우선 본다.
