참가 규칙 v2.1 — 단위는 "판(Run)"

v2.0 2026-09-03 대표 확정 → v2.1 2026-09-06 대표 확정(게스트 정책만 개정) · 2026-09-07 문서 반영. 로그인 사용자 규칙은 v2.0 그대로. HF-1(2026-07-05)의 "하루 새 대회 5개"는 폐기. 이 문서가 참가 규칙의 유일한 정본입니다.

1 확정 규칙

단위 = 판(Run). 한 사람이 한 대회를 48강부터 결승까지 처음부터 끝까지 완주하는 한 번의 여정이 1판이다.
  1. 한도 = 계정당 · 대회당 · 하루(KST) 5판. 대회 A에서 5판, 대회 B에서 5판 — 대회마다 각각 5판.
  2. 비로그인(게스트) = 하루 통틀어 3판. 어느 대회든 자유롭게, 대회 수가 늘어도 3판 고정. 4판째부터 로그인. (v2.1 · 2026-09-06 대표 확정 — v2.0의 1판을 대체. 상세 §4)
  3. 판마다 대진표가 새로 섞인다. 같은 48명이라도 2판째는 다른 대진 → 다른 챔피언이 나올 수 있다.
  4. 판마다 크라운카드가 1장 생성된다. 5판이면 카드 5장.
  5. 로그인 사용자의 판은 랭킹에 5판 전부 반영한다. 회차에 따른 가중치 없음. 단, 게스트의 선택은 랭킹에서 제외한다 (v2.1 — §4).
  6. 한 판 안에서는 매치를 되돌리거나 다시 선택할 수 없다. (현행 유지)

3 폐기 — 다시는 쓰지 않을 표현

제품 정의에서 "표"라는 단위를 쓰지 않는다. "1일 5표" · "하루 230표" · "대회당 최대 46표" · "투표 무제한" 같은 표현은 전부 금지. Vote는 내부 기록(DB)의 이름일 뿐, 사람에게 설명하는 단위는 언제나 "판"이다.
함께 폐기: Daily Vote Limit · Tournament당 하루 5회 투표 · Daily Participation Limit(하루 새 대회 5개) ← HF-1 개념 자체가 폐기됨
새 정본 용어: 일일 판 한도 (Daily Run Limit) = 계정당·대회당 하루 5판

4 게스트 정책 v2.1 (2026-09-06 대표 확정 — v2.0 §4를 전면 교체)

v2.0의 "게스트 하루 1판 · 공유 잠금"은 라이브에서 게스트가 우리에게 아무것도 남기지 않는 흐름(1판 → 공유 막힘 → 다른 대회 진입 시 로그인 창 → 이탈)을 만들었다. 게스트에게 여는 것은 양(판수)과 확산(공유), 로그인에서 얻는 것은 더 많은 양과 소유(저장)와 랭킹 반영이다.

왜 랭킹에서 빼는가 — 가장 중요한 판단

게스트 uid(익명 계정 번호)는 브라우저 창마다 새로 생긴다. 3판 제한은 사람이 아니라 창에 걸리므로, 시크릿 창을 반복해 열면 한 사람이 무한히 돌 수 있다 — 회원의 "대회당 5판" 천장이 게스트에겐 없다.
  • 랭킹에서 빼면 조작 동기 자체가 사라진다. 백 번 열어도 랭킹이 안 움직이면 할 이유가 없다.
  • "내 선택이 랭킹에 반영되려면 로그인"이 새 가입 유인 — 공유를 열어주며 잃은 유인을 여기서 되찾는다.
  • 랭킹 원료 걱정 없음(대표 판단): 공유 카드가 늘어 유입이 늘면 회원의 선택이 그만큼 늘어난다.

3판이라는 숫자

특별한 근거 없음 — "큰 변수가 아니다"(대표, 09-06). "세 번 막히면 로그인한다"는 08-28 판단을 되살린 값. 조정 가능한 값으로 다루며 코드 상수 한 곳(GUEST_DAILY_RUN_LIMIT)에서만 정의한다. 판단 지표 = 게스트 완주 → 로그인 전환율 · 게스트 공유 링크 유입 수.

게스트 안내 3지점 (대표 요구 — RUN-1 PR 2 범위)

게스트가 3판이 있다는 걸 모르면 1판만 돌고 나간다. 표시 위치·존재 여부가 PR 2 범위, 문구 다듬기는 아레나 개편 범위.

  1. 게스트 첫 진입 — 오늘 3판을 돌 수 있다는 안내
  2. 1판 완주 후 Crown Card 화면 — 남은 판수
  3. 판을 다 쓴 뒤 — 로그인 안내로 연결(막고 나서 길을 열어준다)

용어 — "표"는 낱말 자체가 금지 (2026-09-07 대표 확정)

v2.0의 "표를 단위로 쓰지 않는다"에서 한 단계 올라, "표"라는 낱말 자체를 쓰지 않는다. "게스트 표"·"내 표"·"부정표" 전부 금지, 대체어 = 선택. 제품이 투표에서 선택의 개념으로 넘어갔으므로 '표'가 남으면 과거의 투표 의미로 읽힌다. votes·onVote는 코드 내부 이름으로만 존치.
