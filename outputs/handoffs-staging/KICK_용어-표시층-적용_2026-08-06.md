## 1. 스코프 — 정확히 3개 파일 + 검증

- §1 역할 용어 표에 **"표시 용어(Display)" 열 추가**: Voter → ko "팬" / en "Fan" / es "Fan".
- 명시할 예외: 닉네임 없는 사용자의 기본 표시 이름은 "Voter" 유지(대표 결정, 의도된 예외).
- 기사 지표 표기 추가: Voter Count의 기사 표시 = "참여 팬 수" / "Fan Count".
- 하단에 개정 이력 1줄 (2026-08-06, 표시 용어 층 도입, 정의 변경 없음).

### B. `functions/src/core/newsPrompts.ts` 기사 지침 (최우선 목적)
- 기사 본문에서 참여자 지칭 = **"팬"(ko) / "fan(s)"(en/es)**. "Voter"를 독자 대상 텍스트에 쓰지 않도록 지침 문구 수정.
- "비율·순위·Voter Count만 쓴다" → "비율·순위·**참여 팬 수(Fan Count)**만 쓴다"로 교체. 절대 득표수(Vote Count) 금지는 그대로.
- "LANGUAGE.md 공식 용어 준수" 항목에 "단, 독자 노출 지칭은 표시 용어(팬/Fan) 사용" 취지 반영.

### C. `components/policy/ConsentModal.tsx` 문구 3곳
- "Voter 닉네임 자동 채움"(ko) → "팬 닉네임 자동 채움" / en "Voter nickname" → "Fan nickname" / "Voters drop off" → "fans drop off". es 대응 문구 있으면 동일 적용.
