## §0 목적 / DoD

**목적**: 07-10 확정 "The Pitch = 발견 / **Arena 홈 = 활동**"을 구현한다. 대회마다 하나씩 있는 **대기실(전광판)** 에서 팬이 대회를 이해하고, 브래킷 크기를 고르고, 이어하기·입장을 하며, 아래 **카테고리별 아카이브**(진행 중 + 마감 👑)로 다른 대회를 찾아간다.

**DoD**
- [ ] `/arena/{id}` = 그 대회의 대기실. 위 전광판(참가자 썸네일 자동 콜라주 배경 + 제목·설명·카테고리·마감) + 브래킷 크기 `48 · 24 · 12` 선택(시작 후 잠금) + 내 진행(처음 / N번째 매치부터 이어하기 / 완주 → 내 크라운 카드) + **입장하기** 버튼.
- [ ] 입장 → `/arena/{id}/play`(ARENA-1 무대). 기존 딥링크 `/arena/{id}/champion`·`/arena/{id}/ranking` 무변경.
- [ ] 대기실 아래 아카이브: 카테고리 탭(`categories` 컬렉션 순서) → 대회 카드(진행 중 = ACTIVE, 마감 = ENDED + 👑 챔피언 결과 카드). 카드 클릭 → 그 대회의 대기실(`/arena/{other}`)로 이동.
- [ ] `/arena`(ID 없음) → 대표 대회(featured) 대기실로 이동(리다이렉트) — GNB "Arena" 진입점.
- [ ] 브래킷 24/12 선택 시 무작위 추출 + 중간 라운드 시작이 투표 엔진에 반영되고(§4 R1 예외 — 엔진 **확장**), 완주 표 수가 24강=22표·12강=10표로 맞으며 랭킹 집계는 무변경.
- [ ] 전광판 콜라주는 참가자 썸네일 4~6장으로 코드가 자동 배치(제작 0), 썸네일이 4장 미만이면 브랜드 그라디언트 폴백.
- [ ] 문구 전부 i18n(ko/en/es) + 표시 용어 v2.0. ARENA-1의 첫 입장 팝업(M5)은 대기실의 "처음 안내·데이터 고지" 영역으로 **흡수**하고 팝업은 제거.
- [ ] 유닛·통합·E2E(`arena2-lobby`·`arena2-bracket-size`·`arena2-archive`) 100% PASS, Console 에러 0, hex 위반 0. 계측 `lobby_view`·`bracket_size_selected`·`archive_card_click` 신설, 기존 3종 보존.

## §4 RULE

- **R1 엔진은 확장만(additive)** — 기존 48강 Voter의 데이터·흐름 무변경. `bracketSize` 없는 문서 = 48. 새 필드는 생성 시 1회 기록, 이후 불변(브래킷 재선택 금지).
- **R2 Round Scope Lock** — 대기실·아카이브 카드에 라운드 라벨·득표율·참여자 수 없음. 진행 표시는 매치 순번/완주 여부만.
- **R3 콜라주 소재 = 참가자 영상 썸네일만**(외부 이미지 금지, 08-21 법리). 썸네일 위 텍스트 가독성은 딤 레이어(토큰)로.
- **R4 라우트 호환** — `/arena/{id}/champion`·`/ranking` 딥링크·크라운 카드 UTM 링크 무변경. 기존 `/arena/{id}` 진입 링크는 대기실로 자연 승계.
- **R5 raw hex 금지 · 문구 i18n · 승인 게이트 · 애니메이션 라이브러리 금지** (ARENA-1과 동일).

## §5 Phase (v1.0에서 확정)

A 엔진 확장(순수 모듈 + 트리거, 유닛·통합) → B 라우트 이동(`/play`) + `/arena` 리다이렉트(E2E 회귀) → C 대기실(전광판 콜라주·정보·입장) → D 브래킷 크기 선택 + 내 진행 + 처음 안내(팝업 흡수) → E 아카이브(탭·카드·마감 결과 카드·인덱스) → F 문구·계측·규범 문서 → G PR·검증·머지·functions 배포.

## §6 Auto-STOP / 대표 확인 필요

- 대기실 "내 진행"에 라운드명을 쓰지 않고도 이해되는 문구(예: "10번째 매치부터 이어하기")로 충분한지 — **대표 확인**.
- 24/12 선택 시 무작위 추출의 재현성(시드 기반) 규칙이 07-10 문서에 없음 → 제안: 기존 bracketSeed로 48을 셔플한 뒤 앞에서 24/12명 → STOP 후 확인.
- 마감 대회 챔피언 결과 카드의 "챔피언" 정의(Crown Score 1위 vs 누적 점유율 1위) — W4 랭킹 개편과 순서 조율 → STOP.
- 아카이브 인덱스 생성 권한(콘솔) → 사람 절차.

### 대회 썸네일 — 한 그림 세 용도

- **쓰이는 곳 3곳**: ① Pitch `TournamentCard` 커버 ② 아레나 홈 아카이브 카드 ③ 대기실 전광판 배경(제목·설명 오버레이 = "전광판").
- **폴백(썸네일 없음)**: 참가자 유튜브 썸네일 4~6장 **실시간 CSS 콜라주** + 다크 그라데이션 오버레이. 파일로 합성·저장하지 않는다(핫링크 표시 = 현행 그리드와 동일한 법리, 08-08 임베드 전략 유지). 콜라주 참가자 선택 = order 1~6 고정(결정론, 캐시 친화).
- **업로드 그림의 법리(08-28 이미지 정책 적용)**: 파일로 저장되는 그림이므로 크라운 카드 파일과 같은 기준 — 소속사 공개 홍보 이미지·명시적 허락분·또는 대표 제작 브랜드 그래픽만. 유튜브 썸네일 캡처 업로드는 용도 외(폴백이 대신함). 편집기 도움말 문구에 이 기준 명시(문구 승인 게이트).
- 권장 규격: 1200×675(16:9) — Pitch 카드·아카이브 카드·전광판(가로 크롭) 공용. AI 생성 경로(C안)는 보류(대표 결정 09-01) — 필요해지면 별도 검토.
