## §6 Auto-STOP
- 추출을 위해 WC48 코드 수정이 필요해 보임 → STOP(예외 범위 밖).
- 가드 일반화가 2h 초과 예상 → 최소 버전으로 줄이고 보고(STOP 아님), 단 하네스 코드 일반화는 곧바로 README 대체.
- 킷 예시 코드가 WC48 CI에 걸림 → SKIP_DIRS 추가로 해결되면 진행, 아니면 STOP.
- 플레이북과 리포 실물이 모순(예: 플레이북이 말한 파일이 리포에 없음) → 실물 우선, 차이를 보고.
