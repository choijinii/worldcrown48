## §0. 배경

이미지 소싱 1차(K1 CC 이미지 11/48 승인)의 한계 — 합법 소스의 화질·수량 부족, 승인 절차의 비용 — 를 계기로, 대표가 Gemini와 토의하여 "인터넷신문사업자 등록을 통한 미디어 피벗" 명세서를 작성. 2026-07-21 Cowork 세션에서 기존 법리 브리프 v1.0과 대조 검토 후 본 결정 도출.

## §1. 확정 (대표 확정 2026-07-21 — 유일한 확정 사항)

**WorldCrown48은 인터넷신문사업자(대구광역시청 등록)를 추진한다.**

- 1인 발행인·편집인 구조 (취재·편집 인력 고용 요건은 2016 헌재 위헌으로 폐지 → 1인 등록 가능)
- 목적: 숨피형 1층 스택(보도 프레임·프레스킷 접근) 획득, AI 뉴스 팩토리의 법적 기반, 소속사 제휴 명분
- 한계 인지: 등록 = 저작권·퍼블리시티권 자동 면책 아님 (브리프 v2.0 §7.1 "얻지 못하는 것" 참조)

## §3. 클립 파이프라인 — 조건부 채택 (G-LEGAL-3)

**대표 결정:** 백오피스 클립 파이프라인(YouTube URL + 타임스탬프 → 서버 구간 추출 → 자체 호스팅) 방향 채택.

**필수 조건 (게이트 · 2026-07-25 개정):**
1. **G-LEGAL-3(개정)** — 프로덕션 투입 전 **한국저작권위원회 저작권상담센터 무료 자문 1회 + 결과 기록** (전화 1800-5455 · 온라인 · 비용 0원. 유료 변호사 자문은 형편상 무리라는 대표 판단으로 무료 공적 자문으로 대체). 자문 전 허용 범위 = 설계 문서 + 비공개 내부 프로토타입까지
2. 자문 부정 시 기본 대체안 = **임베드 파사드** (hover된 카드만 YouTube 공식 iframe lazy-load, start 파라미터 구간 지정, mute)
3. **아키텍처 원칙**: 미디어 소스는 image | embed | clip 3종 스왑 구조 — 등록 완료일에 클립 없이도 시스템 100% 가동, 클립은 크리티컬 패스 제외

**Cowork 이견 병기:** 복제권 침해 소지·YouTube 약관 위반·"로고 제거"의 고의성 정황 리스크로 반대 의견 제시함. 07-13 합의(임베드 최강 카드)와 상충. 상세 → 브리프 v2.0 §7.3

## §6. 추가 결정 (2026-07-25~26 개정)

**6-1. 실행 타임라인 — "시스템이 먼저, 등록이 나중" (대표 확정 07-25)**
심사 때 실제 돌아가는 뉴스 사이트를 보여줘야 하므로 시스템 전체가 등록보다 선행한다:

```
[1] 지금       News Desk 구축 + 토너먼트 운영 (소싱 연료 = CC 승인분 11명 + 임베드 + 자체 그래픽)
[2] +2~4주     기사 축적 (주 2~3건 발행 리듬)
[3] 신청       대구시청 접수 → 심사 약 20일
[4] 등록 완료   프레스킷 소싱 개시 → image 슬롯 업그레이드
[5] 자문 반영   clip 슬롯 활성 여부 확정
```

**6-2. G-LEGAL-3 이행 — 저작권 상담 접수 완료 (2026-07-26)**
한국저작권위원회 상담센터 온라인 상담 접수 완료 (7문항, 1500자 축약판 제출). **답변 예상 ~2026-08-02.** 질의서 = `docs/legal/WC48_저작권상담_질의서_v1_2026-07-25.md` (하단에 답변→시스템 반영 매핑표). 답변 수령 시: PDF 보관 → 매핑표대로 결정 → 브리프 v2.1 갱신. 유료 변호사 자문은 형편상 보류하고 무료 공적 자문으로 대체(온라인 = 서면 기록 확보).

**6-3. 스왑 구조(그릇) vs 클립 파이프라인(공장) 구분**
Contestant 미디어 소스 = image | embed | clip 3종 스왑 구조(그릇) — 법적 쟁점 없어 즉시 개발 가능, 클립 없이도 시스템 100% 가동. 클립 파이프라인 = clip 부품을 만드는 백오피스 공장 — 자문 대상은 이 공장이며 크리티컬 패스에서 제외.

**6-4. ComfyUI 활용 원칙 (07-25)**
유튜브 캡처 기반 AI 변형·실존 인물 생성 금지 (복제 + 2차적저작물 + 초상권 3층 침해 소지, AI ≠ 권리 세탁, 팬덤 반발 리스크). ComfyUI는 **인물 없는 자체 에셋 공장**(카드 배경·히어로 아트·뉴스 그래픽·Crown Card 아트)으로 활용 — 합법 최대치 전략 ③(디자인으로 화질 격차 상쇄)의 실행 엔진.
