- [ ] 단위 테스트 green, 신규 테스트 포함 · hex guard · tsc · build 통과

## §1 필독 컨텍스트 (인라인 — 외부 메모리 참조 없음)

현재 실측(2026-08-16 Claude Code 조사): `functions/src/core/models.ts:12-13`이 단일 소스. `HAIKU_MODEL = claude-haiku-4-5`(키워드 생성 max_tokens 512, 번역·뉴스 초안도 공유), `SONNET_MODEL = claude-sonnet-4-6`(48명 채우기 max_tokens 4096). 경로 `TournamentCreator.tsx → httpsCallable → Functions v2(asia-northeast3, maxInstances:10) → @anthropic-ai/sdk`, 키 `defineSecret("ANTHROPIC_API_KEY")`. 두 콜러블은 `req.auth?.uid`만 확인, 인스턴스별 5회/분 버킷만 있음. `aiFillContestants.ts:19-21` 주석에 "교차 인스턴스 일일 캡(50/day)은 Firestore 카운터 필요 — 후속"으로 열려 있음. CLAUDE.md 스택 표는 `claude-sonnet-4-20250514`라고 적혀 있어 오기.

대표 결정(2026-08-16): **업그레이드는 무조건 진행.** 단 Claude Code가 지적한 대로 한 줄 교체가 아님 — 최신 Sonnet은 적응형 사고(thinking)가 기본이라 `max_tokens`가 사고+응답 합산 상한이고, 토크나이저 변경으로 같은 텍스트가 ~30% 더 많은 토큰이 될 수 있음.

## §3 스코프
**IN**: 모델 상수 교체 · thinking 옵션 명시 · max_tokens 재산정 · requireAdmin 2건 · 일일 캡(Firestore) · CLAUDE.md 정정 · 골든 테스트 · 비용 실측 로그.
**OUT**: 프롬프트 문구 변경, UI 변경, LAB-EV-2 기능(URL·메타데이터 생성), 번역·뉴스 함수의 모델 변경(HAIKU 유지), MVP2용 유저별 쿼터(후속).

## §4 RULE
- R1 출력 JSON 스키마 불변 — `parseContestants`·키워드 파서가 수정 없이 통과해야 함.
- R2 키는 Secret Manager 전용, 로그에 키·프롬프트 전문 남기지 말 것(토큰 수만).
- R3 시각 결과 무변경(UI 손대지 않음), hex guard 통과.
- R4 모델 ID·단가는 **docs.claude.com 실측**으로 확인 후 사용, 추측 금지.
- R5 사고(thinking) 처리: 48명 채우기는 구조화 JSON 작업이라 **thinking 비활성(`{type:"disabled"}`) 기본**. 품질 저하가 골든 테스트에서 보이면 STOP 후 보고(활성+상한 상향은 대표 결정).

## §5 Phase
- **A** models.ts: `SONNET_MODEL` 최신 ID(문서 확인) + 콜 옵션에 thinking disabled + `max_tokens` 4096→8192(LAB-EV-2 메타데이터 여유). 골든 테스트: 실제 API로 기존 프롬프트 3회 → 파싱 성공·48명·중복 없음 확인, 입출력 토큰·비용 기록. HAIKU는 유지하되 **더 최신 Haiku가 문서에 있으면 단가·ID만 보고하고 교체는 STOP**(대표 결정).
- **B** requireAdmin 2건(LAB-EV-1과 같은 유틸) + Firestore 일일 카운터(`aiUsage/{yyyy-mm-dd}` 트랜잭션 증가, 기본 50, env로 조정) + 초과 시 `resource-exhausted` + 단위 테스트(어드민 아님 거부 / 51회째 거부 / 날짜 롤오버).
- **C** CLAUDE.md AI 줄 정정(모델 ID 2개 + "단일 소스 models.ts" 명시).
- **D** PR(4블록) → CI → 프리뷰 SHA 확인 → **대표 스모크**: /admin/lab에서 [AI 키워드 생성]·[AI 48명 전체] 실제 실행, 결과 품질을 이전과 비교(대표 눈) → 머지·배포(main 전용) → 배포 후 함수 로그에서 새 모델 ID 확인.

## §6 Auto-STOP
- 최신 Sonnet ID가 API에서 404/권한 오류 → STOP(계정 접근권 문제일 수 있음).
- 골든 테스트 3회 중 1회라도 파싱 실패 또는 48명 미만 → STOP(thinking 활성/상한 상향/프롬프트 미세조정 중 대표 결정).
- 기존 admin 판정 유틸이 없거나 LAB-EV-1과 다른 방식 → STOP.
- 단가·모델 문서를 확인할 수 없음 → STOP(추측 금지).
- 더 최신 Haiku 존재 → 보고 후 STOP.
- 일일 캡 구현이 기존 5회/분 버킷과 충돌 → STOP.
