## Phase 2 — 고치기

### 부품 선택: `canvas` 3.2.3 (`@napi-rs/canvas` 아님)
| | canvas 3.2.3 | @napi-rs/canvas 1.0.10 |
|---|---|---|
| Node 22 설치 파일 | ✅ `canvas-v3.2.3-napi-v7-linux-x64` (N-API — Node 버전 무관) | ✅ 플랫폼별 패키지 |
| 그리기 엔진 | **Cairo — 지금과 같음** | Skia — 글꼴·윤곽 결과가 달라질 수 있음 |
| API | `createCanvas`·`getContext('2d')`·`toBuffer('image/png')` **그대로** | 대체로 같으나 엔진이 다름 |

리눅스 설치 파일이 Cloud Functions(Ubuntu 22.04 기반, glibc 2.35)에서 도는지: 내려받아 바이너리가 요구하는 glibc 최고 버전을 읽었다 → **`GLIBC_2.28`** (≤ 2.35). cairo·pango 등 의존 라이브러리가 설치 파일 안에 함께 들어 있다(`build/Release/libcairo.so.2` 등).

### 바꾼 것
- `functions/package.json`: `optionalDependencies.canvas ^2.11.2` 삭제 → `dependencies.canvas ^3.2.3` (**필수 설치** — 설치가 실패하면 배포가 실패한다). 잠금 파일 변화는 canvas 하위 부품(node-pre-gyp 계열 → prebuild-install 계열)뿐.
- `functions/src/core/canvasServer.ts`: **주석만** — "node-20 · optional" 전제를 실제(3.x 필수 의존성, 이 사고의 경위)로 정정. 그리기 코드(`drawLink` 호출)·`require` 위치 무변경.

### 그림 결과
`outputs/CARD-FIX_캡처_2026-10-04/` — 실제 `renderCrownPng`(빌드된 functions/lib) 로 그림:
- `server-card_hf3-seed_P1.png` (hf3 시드: 이름 P1 · 대회 "Guest Run hf3-guest-e2e-a")
- `server-card_sample_ko-name.png` (한글 섞인 이름 확인용)
- 비교용 `client-card_chromium_*.png` — 같은 데이터·같은 `drawLink` 를 Chromium 이 그린 것(팬이 받는 클라이언트 카드와 같은 경로)

| 비교 (서버 canvas 3 vs Chromium) | 차이 > 8 | 차이 > 64 |
|---|---|---|
| hf3 시드 P1 | 4.94% | 2.78% |
| 한글 이름 | 7.84% | 5.44% |

차이는 **글자 간격과 굵기**에 몰려 있고 배치·색·크기·왕관은 같다. 원인: Chromium 은 `ctx.letterSpacing` 과 굵은 글꼴을 적용하고 node-canvas 는 `letterSpacing` 을 지원하지 않는다 — canvas 3.x 변경 이력에도 letterSpacing 추가가 없어 **2.x 때부터 같은 차이**다(`canvasServer.ts` 머리 주석의 "서버 PNG 는 클라이언트와 1~2px 차이 허용 · handoff §9 trap #7" 범위의 서버/브라우저 차이).

**한계(정직하게)**: 옛 canvas 2.11.2 그림과 픽셀 비교는 못 했다. 이 Mac(arm64)용 2.11.2 설치 파일이 없고, Rosetta·Docker 가 없으며, 소스 컴파일엔 Homebrew 패키지(pango·jpeg·librsvg) 설치가 필요해 하지 않았다. 남는 위험 하나: canvas **3.1.0 이 `ctx.font` 해석기를 새로 썼다**("Please file an issue if you experience different results"). 같은 Cairo/Pango 엔진이라 눈에 띄는 차이는 예상하지 않지만 확인된 사실은 아니다. 또 이 PNG 는 **이 Mac 의 글꼴**로 그려졌다 — 운영 서버는 그 서버에 있는 글꼴로 그리며, 이는 2.x 때도 같았다.
