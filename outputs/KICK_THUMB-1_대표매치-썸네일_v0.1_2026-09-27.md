## §0 한 줄 요약
대회 썸네일을 "엔트리 1~6번 자동 콜라주"에서 **"주인이 고른 대표 매치 2개의 VS 장면"**으로 바꾼다. 편집기에서 48개 중 2개를 누르면 미리보기가 바로 바뀌고, 확정하면 The Pitch 카드·아레나 홈(아카이브 카드·대기실 전광판)에 그 장면이 나온다.

## §1 대표 제안 (2026-09-27, 원문 요지)
1. 썸네일 내용 = **가장 대표되는 매치의 장면**
2. 대표 매치 = 편집기 2단계(STEP 2)의 48 그리드에서 **2개를 선택**해 매치 장면 연출
3. 썸네일 편집기 — 48개 중 대표 2개를 클릭할 때마다 **매치 장면이 바뀜**(미리보기)
4. 확정하면 **아레나 홈과 피치에서 썸네일이 보임**

## §3 티오 의견 — 왜 대표 안이 더 좋은가
- **서비스가 한눈에 설명된다.** "이 둘 중 누구?" — VS 장면이 곧 WorldCrown48의 핵심 행동(선택)이다. 1~6번 콜라주는 "사진 모음"일 뿐.
- **클릭을 부른다(마케팅).** 피치 카드에서 대결 구도가 보이면 호기심이 생긴다. 대회 주인이 "화제가 될 매치"를 고를 수 있다.
- **제작 0 원칙과 같다.** 새 그림을 만들지 않고, 이미 있는 엔트리 썸네일 2개를 고르기만 한다.
- **매치 무대와 같은 부품을 쓴다.** 포스터 자르기(`lib/media/stageCrop.ts`, 원장 D-11·D-15)를 재사용 → 무대에서 보던 그 얼굴 자리가 썸네일에도 그대로.

## §4 정할 것 5가지 (다음 세션 대표 결정)
1. **ⓐ 업로드 칸을 남길까?** — 티오 추천: **남긴다(선택 항목, 있으면 우선)**. 이유: 공식 프레스킷 포스터가 있는 대회(예: 소속사 제공 이미지)는 그게 더 좋다. 없으면 대표 매치. / 대안: 없앤다(편집기 단순화).
2. **2개를 안 고르면 기본값?** — 티오 추천: **엔트리 순서 1번 vs 2번**(결정론·캐시 친화). / 대안: 게시 전에 반드시 고르게 막기(필수 항목).
3. **차트가 열린 뒤 자동 교체 옵션?** — Crown Score 1·2위로 썸네일이 저절로 바뀌는 "지금 가장 뜨거운 매치" 모드. 티오 의견: 매력적이지만 **런칭 후 별도**(차트는 10판 뒤에 열리고, 하루 두 번 바뀌면 카드가 계속 달라져 혼란). 이번엔 주인이 고른 고정값만.
4. **자르기** — 16:9 칸을 반반 나누면 각 칸은 8:9(거의 정사각). 얼굴이 잘릴 수 있다. 티오 추천: 매치 무대와 같은 규칙(가로 영상 = 가운데, 세로 = 위 40%) 그대로 + **편집기 미리보기에서 대표가 확인**. 칸별 위치 조정 슬라이더는 런칭 후.
5. **언제 하나?** — 이미 정한 런칭 전 순서: E2E-1 → COOKIE-1 → NAV-1 → FONT-1 (BANNER-1 나중). 지금 피치 카드 커버는 "48 VS" 글자뿐이라 런칭 첫인상에 영향이 크다. 티오 추천: **NAV-1 다음, FONT-1 앞**(또는 대표 판단). ARENA-2(아레나 홈 대기실·아카이브)는 런칭 후라, 런칭 전에는 **피치 카드 커버에만** 먼저 적용하고 아레나 홈은 ARENA-2 때 같은 부품을 쓴다.

## §5 화면 그림 (초안 — 디자인 정본은 클로드 디자인, 원장 D-20)
```
편집기 STEP 2 (48 그리드 위쪽)
┌ 대표 매치 썸네일 ─────────────────────────────┐
│  ┌──────────┬──────────┐   48개 중 2개를 누르세요 │
│  │  엔트리 A │  엔트리 B │   [A: 12번] [B: 31번]   │
│  │   (얼굴)  VS  (얼굴)  │   [바꾸기] [확정]        │
│  └──────────┴──────────┘                         │
│  미리보기: [피치 카드] [아카이브 카드] [전광판]      │
└──────────────────────────────────────────────┘
그리드 칸 → 누르면 A → 다시 다른 칸 → B → 세 번째 누르면 A부터 교체
```
- 피치 카드 커버: 왼쪽 A · 가운데 **VS** 표식 · 오른쪽 B + 아래 어둡게(딤 토큰) 위에 대회 제목.
- 배너 자리(원장 D-21): 썸네일 자체에는 배너 없음. 편집기 화면은 관리자 전용이라 배너 자리 해당 없음 — **v1.0에서 재확인**.

## §6 데이터 (초안)
- Tournament 문서에 `thumbnailPair: [contestantIdA, contestantIdB]` 추가(additive, 기존 문서 무영향). 없으면 §4-2 기본값.
- 고른 엔트리가 나중에 삭제·교체되면 → 기본값으로 자동 폴백(빈 칸 금지).
- 규칙: 쓰기 = 대회 주인(hostUid)만(기존 tournaments 규칙 그대로). 읽기 = 기존 규칙.
- 계측 후보: `thumbnail_pair_set`(편집기) — EVENT_SPEC 대조 후 확정.

## §7 지키는 규칙
- **파일로 합성·저장 금지**(법리) · 외부 이미지 금지(엔트리 썸네일만) · raw hex 금지(토큰) · 화면 문구 3언어 + 승인 게이트 · Round 라벨 금지(Round Scope Lock) · LIVE 뱃지 금지 · 전투 은유 금지(축제의 언어 — "VS"는 기존 매치 무대 표식 그대로).
- 공유 미리보기 그림(OG 이미지)은 이 킥에서 바꾸지 않는다(파일이 필요해 법리 판단이 다름).
