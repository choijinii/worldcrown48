3 대표님이 하실 일 — 명령 3줄 + 붙여넣기

1단계

터미널을 열고 프로젝트 폴더로 들어가면서, 지금 어느 가지에 서 있는지 확인합니다.

cd ~/Projects/worldcrown48 && git branch --show-current

✅ 성공 신호 — 화면에 feat/run-1-participation-v2 한 줄이 뜹니다.

2단계

티오가 작업할 때 남긴 임시 찌꺼기 파일을 지웁니다. (티오 쪽 연결에는 파일 삭제 권한이 없어 .git/_to_delete 폴더에 모아만 뒀습니다. 안 지워도 동작에는 지장 없지만, 깔끔하게 털고 가는 편이 좋습니다.)

rm -rf ~/Projects/worldcrown48/.git/_to_delete

✅ 성공 신호 — 아무 메시지도 안 뜨면 성공입니다.

3단계

같은 폴더에서 Claude Code를 켭니다.

claude

✅ 성공 신호 — 입력창(프롬프트)이 나타납니다.

4단계 · 붙여넣기

outputs/PROMPT_ClaudeCode_RUN-1_2026-09-04.md 파일을 열어, ---8<--- 여기서부터 복사 와 ---8<--- 여기까지 복사 사이를 통째로 복사해 Claude Code 입력창에 붙여넣고 엔터.

✅ 성공 신호 — Claude Code가 먼저 자가 검증 5줄(✓ CLAUDE.md, ✓ LANGUAGE.md …)을 출력합니다. 여기서 ✗가 하나라도 나오면 진행하지 말고 티오에게 알려 주세요.

Claude Code는 첫 동작으로 git fetch origin → git rebase origin/main을 돌려 원격 저장소의 최신 상태 위에 이 작업을 올립니다. 티오가 쓰는 클라우드 쪽에는 SSH 키(원격 저장소 출입증)가 없어 티오는 이 단계를 대신 못 합니다 — 그래서 Claude Code의 첫 일로 넣어뒀습니다.
