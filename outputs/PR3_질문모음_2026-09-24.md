## Q5. ModuleNav 탭 글자를 3언어로 만들까 (§5 표 row 19 · **제가 놓쳤던 질문**)

**무엇** — 대표 지시: *"ModuleNav는 이번 PR에서 지우지 말고, 탭 글자 'Ranking'을 차트 이름으로 — 초안 ko '차트' / en 'Chart' / es 마케팅 대기."*

**왜 묻는지** — `lib/arena/moduleNav.ts:24~29` 의 `MODULE_TABS` 는 지금 **언어 개념이 없는 영문 고정 배열**입니다:

```
{ key: "vs",       label: "VS Battle"  }
{ key: "crown",    label: "Crown Card" }
{ key: "ranking",  label: "Ranking"    }   ← 이것만 바꾸라는 지시
{ key: "newsroom", label: "Newsroom"   }
```

ko "차트"를 넣으려면 이 배열을 **3언어 구조로 바꾸고 `ModuleNav.tsx`에 언어를 주입**해야 합니다. 그러면 나머지 세 탭도 같이 건드리게 되고, ModuleNav는 **NAV-1 소관**입니다.

**선택지**
- **(가) 영문 단일 교체** — `Ranking` → `Chart`. 한 낱말. NAV-1과 충돌 없음. ko 화면에도 "Chart"로 보입니다(지금 다른 세 탭과 같은 방식).
- **(나) 지시대로 3언어화** — ko 차트 / en Chart / es 대기. `MODULE_TABS` 구조 변경 + `ModuleNav.tsx` 수정. NAV-1이 이 파일을 다시 뜯을 예정.

**제 추천 — (가) 영문 단일 교체.**
같은 줄의 `VS Battle`·`Crown Card`·`Newsroom`이 전부 영문 고정이라, `Ranking`만 "차트"가 되면 **한 줄 안에서 언어가 섞입니다.** 탭 줄 전체의 3언어화는 NAV-1에서 한 번에 하는 편이 낫습니다. 다만 "ko 화면에 차트라는 낱말이 반드시 보여야 한다"가 지시의 핵심이라면 (나)로 가겠습니다.
