ARENA-2 · 모양 ① vs ② 그림 설명

"대회마다 하나씩"과 "허브 한 장"의 차이 — 팬이 실제로 밟는 걸음으로

한 표로 비교

항목① 대회마다 하나씩② 허브 한 장 (+ ?t=ID)
다른 대회 고를 때페이지 이동(대기실 → 대기실)제자리에서 전광판 교체(빠름, 탐색에 강함)
대회별 공유 링크/arena/A (자연스러움)/arena?t=A (동일하게 가능)
검색 엔진(SEO)대회마다 독립 페이지 — 유리한 페이지 — 대회별 색인은 무대(/arena/{id}) 메타로 보완 필요
The Pitch와 경계Pitch = 발견 / 대기실 = 그 대회 활동 — 선명Pitch(트렌딩)와 아카이브(전체)가 비슷해 보일 수 있음 → Pitch는 "추천·히어로·기사", 아레나 홈은 "전체 목록·내 진행"으로 역할 분리
구현 규모중 — 기존 /arena/{id}를 대기실로, 무대는 상태 전환중 — /arena 신설 + 선택 상태 관리 + 무대 진입
크라운 카드 딥링크(/arena/{id}/champion)같은 가족무대 주소 아래라 그대로 유지
티오 의견: 대표님이 그리신 "전광판 대기실 + 아카이브 = 한 장"은 ②가 맞습니다. ②에 ?t=대회ID만 붙이면 ①이 가진 공유·뒤로가기 장점을 다 가져오므로, ②로 확정해도 손해가 없습니다. 남는 숙제 하나: "매치 대표이미지" — 지금 대회 데이터에 대표 이미지 칸이 없습니다(그림은 전부 참가자 영상 썸네일). 편집기에 "대표 이미지" 칸을 새로 만들지, 참가자 썸네일 4~6장을 자동 콜라주해서 전광판 배경으로 쓸지 정해야 합니다(후자는 제작 부담 0, 전자는 대표님이 대회마다 그림 준비).
