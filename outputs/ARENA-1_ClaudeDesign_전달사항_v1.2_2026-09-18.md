# ARENA-1 · 클로드 디자인 전달사항 v1.2 (2026-09-18)

프로젝트 "K-pop 아이돌 VS 무대 디자인" · 파일 Arena Match Stage.dc.html · 승인 대표

## 0. 먼저 — 작업 방식 (가장 중요)
- **지금 파일의 현재 상태가 정본이다.** 대표가 Edit 모드로 직접 고친 값(무대 프레임 1320×680, 띠 투명도, 띠 위 글씨 배치, 포스터)을 **먼저 파일에서 읽어서 목록으로 보고**한 뒤에 작업을 시작하라. 기억 속의 옛 상태로 되돌리지 마라.
- **다시 생성하지 말고 부분 수정만 하라.** 무대 프레임 안쪽은 한 글자도 바꾸지 않는다. 바꾸는 곳은 메뉴바, 메뉴바 아래 한 줄, ☰ 서랍뿐이다.
- 작업 뒤에 "바꾼 것 / 안 바꾼 것"을 두 줄로 보고하라.

## 0-1. 폐기 컨셉 경고
"WorldCrown48 아레나 무대 리디자인"(축구 선수·축구 경기 컨셉)은 폐기된 프로젝트다. 참조 금지. 세계관은 K-pop 무대 대결(스포츠 문법).

화면 1A는 합격이다. 프레임 1320×680 · 칸 640 · 띠 투명도(현재 값) · 모바일 가로 366 정사각 — 전부 확정. 이번 요청은 **메뉴바와 그 아래 한 줄, ☰ 서랍**만 고친다. 무대는 건드리지 않는다.

## 1. 메뉴바(높이 64) — 고칠 것 4가지
| 지금 (1A) | 고친 뒤 |
|---|---|
| ☰ 없음 | 왼쪽 끝(로고 앞)에 ☰ 복원. 실제 사이트에 이미 있는 부품 |
| The Pitch · The Lab · The Arena · Locker Room | **The Pitch · The Arena · Newsroom · Locker Room** — The Lab은 운영자 전용이라 팬 메뉴에서 제외, Newsroom 추가 |
| 오른쪽: KO · 노란 버튼 "선택 이어가기" | 오른쪽: **KO 토글 → 로그인 버튼(비로그인) 또는 아바타 32px(로그인)**. 노란 버튼은 메뉴바에서 삭제 — 2절로 이사 |
| — | 아트보드 2장: 비로그인 상태 / 로그인 상태 (오른쪽 끝만 다름) |

모바일 세로(390): 메뉴 단어 4개는 숨기고 ☰ · 로고 · KO · 로그인/아바타만. 모바일 가로(844×390): 메뉴바 없음(변경 없음).

## 2. "선택 이어가기" 버튼 — 새 자리
층 구조: ① 메뉴바(64) → ② 안내 문구 층(The Arena / 대회 제목 / 설명) → ③ 무대 프레임 1320×680 → ④ 배너.
버튼은 ①이 아니라 **② 안내 문구 층의 오른쪽 끝, 아바타와 세로 정렬**. 그래서 KO·아바타와 절대 겹치지 않는다.

| 항목 | 확정 |
|---|---|
| 보일 조건 | 끝내지 않은 참여가 있을 때만. 없으면 그 자리는 비어 있다(자리 잡아 두지 않음). 그 대회의 매치 화면에서는 숨김 |
| 모양 | 노란 알약(Crown Gold #FCD006), 높이 28~32, 글자 굵게. 강조색은 이 버튼 하나뿐 — 주변에 다른 노란 요소 금지 |
| 3언어 문구 | ko **선택 이어가기** · en **Continue your picks** · es **Continuar tus elecciones** |
| 비로그인 | 로그인 버튼 밑, 같은 자리 |
| 모바일 세로 | 같은 규칙, 오른쪽 끝. 모바일 가로: 없음 |
| 그릴 상태 | 5절 참조 — 있음 상태만 그린다 |

## 3. ☰ 사이트맵 서랍 — 재설계
참조: **GitHub 왼쪽 햄버거 패널.** 박스가 층층이 쌓인 카드 목록이 아니라, **단어만 깔끔히 세로로 나열**하고 오른쪽 **▸ 토글**로 하위 페이지를 펼치는 형태. 왼쪽에서 밀려 나오는 서랍, 폭 데스크톱 320 / 모바일 화면폭−56. 바탕은 메뉴바와 같은 다크, 글자 흰색, 강조는 Crown Gold 한 곳(현재 페이지 표시).

목록 — 실제로 존재하는 페이지만:
```

Locker Room           내 Crown Card · 프로필  ← 한 페이지라 토글 없음
Policy Hub         ▸  (열면) 개인정보처리방침 · 이용약관 · 커뮤니티 가이드 · 쿠키 정책
──────────────
언어  KO · EN · ES
로그인 / 로그아웃
──────────────  (관리자로 로그인했을 때만 보임)
```

- 제외: Launch Pad(사전등록 페이지), 그리고 팬에게 The Lab·Admin.
- 낱말 금지: "투표·Vote·표·예측·배당". 설명글이 필요 없으면 쓰지 않는다(단어만).
- 그릴 상태: 5절 참조 — 열린 상태 데스크톱 1장(Policy Hub 펼침) + 모바일 1장.

## 5. 산출물 — 같은 디자인의 상태 4개 (고르는 시안이 아니다)
아래는 서로 다른 시안이 아니라 **한 디자인이 상황에 따라 보이는 4가지 상태**다. 기존 1A 아트보드를 고치고, 서랍 열린 상태만 새로 추가한다.
1. 데스크톱 1440 — 로그인 상태(아바타) + "선택 이어가기" 있음 (기존 1A 데스크톱 아트보드를 고친다)
2. 모바일 세로 390 — 로그인 상태 + "선택 이어가기" 있음 (기존 1A 모바일 세로 아트보드를 고친다)
3. ☰ 서랍 열림 — 데스크톱 (새 아트보드 1장, Policy Hub 펼친 상태로)
4. ☰ 서랍 열림 — 모바일 세로 (새 아트보드 1장)
비로그인 상태·버튼 없는 상태는 그리지 않는다 — 오른쪽 끝 요소 하나만 다르므로 글로 적어 두면 된다.
