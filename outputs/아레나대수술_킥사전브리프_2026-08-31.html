3 마케팅 "확인 필요 — 티오" 3항 답변 (대관 연출 인계 §8)

질문실측 답
① 실제 화면 규격대수술 후 매치·결승·대관은 뷰포트 전체(100vw × 100vh)를 씁니다. 모바일 세로 390×844 가정은 유효하고, 데스크톱은 가로가 넓어지므로 크라운은 "화면 짧은 변의 %"로 배치합니다(예: 크라운 폭 = min(vw, vh)의 36%). 따라서 자산은 제안하신 3배 크기 그대로 OK, 데스크톱에서는 SVG 크라운이 벡터라 손실 없음, PNG 광채(960px)도 데스크톱 최대 표시 ≈ 400px이라 충분합니다.
② 애니메이션 도구저장소에 애니메이션 라이브러리가 없습니다(package.json 실측: framer-motion·gsap·react-spring 0건, 규범 문서도 "CSS transition/keyframes"). 대관 연출은 CSS keyframes + Web Animations API(브라우저 내장)로 구현 — 위치·크기·회전·투명도만 쓰는 제약과 정확히 맞고, 탭 건너뛰기는 animation.finish() 한 줄입니다. 새 도구 도입 불필요.
③ crown_main.svg 저장 형태대표님께 요청 사항: (a) 채우기 색을 고정 hex 대신 fill="currentColor"(또는 var(--crown-gold))로 — 대관 순간 금색이 밝아지는 연출을 CSS로 처리. (b) 그림자·광채 효과는 SVG 필터로 넣지 말고(모바일 끊김) PNG 광채 층에 맡기기. (c) viewBox 정사각(0 0 420 420), 크라운 바닥선이 viewBox 아래에서 8% 지점에 오도록(하강 후 "닿는" 기준선 계산용). (d) 텍스트·폰트 포함 금지, 패스만.
