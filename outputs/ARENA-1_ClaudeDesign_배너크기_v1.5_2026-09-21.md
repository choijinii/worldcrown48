# 클로드 디자인 지시 v1.5 — 배너 자리 크기 교체 (2026-09-21)

## 0. 작업 방식 (어기면 불합격)
- **기준 = 지금 파일 상태(아트보드 9장).** 되돌리지 말고, 다시 생성하지 말고, 아래 적은 것만 바꾼다.
- 무대 프레임·칸·VS·띠·안내 문구 층·메뉴바·서랍·Tweaks 값은 **손대지 않는다.**
- 끝나면 "바꾼 것 / 안 바꾼 것" 두 줄 보고.

## 1. 바꿀 것 — 배너 자리 크기만
| 아트보드 | 지금 | 바꿀 것 |
|---|---|---|
| 1~5 (데스크톱 1440) | 배너 1320×140, 무대 프레임 아래 | **970×90**, 무대 프레임 아래 같은 위치(top 그대로), **가로 가운데 정렬** (left = (1440−970)/2 = 235) |
| 6~8 (모바일 세로 390×844) | 배너 없음 또는 366×문구 | **320×100**, 무대 프레임 아래 12px 띄워서, **가로 가운데 정렬** (left = 35) |
| 9 (모바일 가로 844×390) | 없음 | **그대로 없음** |

- 배너 상자 스타일은 기존 토큰 그대로: 배경 rgba(36,23,84,.4) · 테두리 1px dashed rgba(255,255,255,.16).
- 상자 안 내용: 기본 공지 한 줄(ko) **"로그인하면 크라운 카드를 간직하고, 대회마다 하루 5번 참여할 수 있어요"** — 글자는 Pretendard 14px(모바일 13px), 색 #DDDDEA, 가운데 정렬. 이미지·광고 시안을 만들지 마라.
- 디자인 시스템의 배너 부품(BannerSlot)도 같은 두 크기로 갱신: 변형 2개 = `desktop 970×90` · `mobile 320×100`. 옛 `1320×140` 변형은 지운다.

## 2. 이유 (기록용, 디자인에 쓰지 말 것)
원장 D-21 바뀜(2026-09-21): 배너 자리 = 구글 광고 표준 크기. 자리 안에 광고를 넣는 방식은 공간 낭비라 폐기.
