## 1. 사전등록 계측

### `waitlist_submit`

사전등록 폼 제출 성공 시 발생.

| 파라미터 | 내용 |
|---|---|
| `utm_source` | 첫 진입 시 저장된 값 |
| `utm_medium` | 〃 |
| `utm_campaign` | 〃 |
| `utm_content` | 〃 |
| `founding_rank` | 파운딩 보터 순번 (200 이내 여부 판정용) |

**UTM 유지 규칙**
1. 첫 진입 시점에 UTM 5개를 저장한다
2. 이미 저장된 값이 있으면 덮어쓰지 않는다 (첫 유입 출처 보존)
3. 저장 기간 **7일**
4. 제출 시 저장된 값을 이벤트 파라미터로 함께 보낸다

> UTM이 빠지면 사전등록 500명을 모으고도 **어느 팬베이스가 만든 등록인지 알 수 없습니다.**
> 총공 3일에 어디를 밀어야 할지 판단할 근거가 사라집니다.

`founding_rank`는 파운딩 보터 200석 마감 시점을 실시간으로 알기 위한 값입니다.
마감 자체가 홍보 소재이므로, 언제 마감되는지를 마케팅이 알아야 합니다.

## 2. 대관 연출 계측 (신설)

### `ceremony_viewed`

대관 연출이 정지 프레임까지 도달했을 때 발생.

| 파라미터 | 내용 |
|---|---|
| `reduced_motion` | 모션 최소화 설정 여부 (true/false) |
| `tournament_id` | 어느 대회의 결승인지 |
| `match_session_id` | **아래 3항 참조** |

### `ceremony_skipped`

움직임 도중 탭해서 건너뛰었을 때 발생.

| 파라미터 | 내용 |
|---|---|
| `elapsed_ms` | 시작부터 탭까지 경과 시간 |
| `tournament_id` | 어느 대회의 결승인지 |
| `match_session_id` | **아래 3항 참조** |

**두 이벤트로 알고 싶은 것**
- 끝까지 보는 비율 — 연출이 붙잡고 있는가
- 몇 초에 넘기는가 — 2.5~3초가 적정한가, 줄여야 하는가
- 반복 이용자일수록 빨리 넘기는가 — 그렇다면 연출은 그대로 두고 건너뛰기만 더 쉽게

## 3. `match_session_id` — 신규 요청

### 왜 필요한가

`ceremony_viewed` / `ceremony_skipped` 두 이벤트만으로는 **"본 사람 대 넘긴 사람" 비율**까지만 알 수 있습니다.

정작 알아야 하는 것은 그 다음입니다.

> **끝까지 본 사람이 실제로 더 많이 공유했는가?**

이게 나와야 대관 연출이 공유율에 기여했는지 판정할 수 있고,
아니라면 3초를 들일 이유가 없습니다.

### 무엇이 필요한가

**한 사람의 한 판**을 식별하는 값 하나를, 아래 이벤트에 공통으로 실어 주십시오.

- `ceremony_viewed`
- `ceremony_skipped`
- 크라운 카드 생성 이벤트
- 크라운 카드 공유 이벤트 (X · 네이티브 공유시트)

값의 형식은 개발 편한 대로입니다. 대회 ID가 아니라 **판 단위**여야 합니다.
같은 사람이 하루 5판을 하면 5개의 서로 다른 값이 나와야 합니다.

### 이 값으로 볼 수 있게 되는 것

| 질문 | 답이 나오는 방식 |
|---|---|
| 대관 연출이 공유를 늘리는가 | 끝까지 본 판의 공유율 vs 건너뛴 판의 공유율 |
| 어느 대회의 공유율이 높은가 | `tournament_id`별 공유 전환율 |
| 몇 번째 판부터 공유가 줄어드는가 | 같은 사용자의 판 순서별 공유율 |

세 번째가 특히 중요합니다. **하루 5판 구조에서 몇 판째까지 공유 의욕이 유지되는지**를 알면,
쿼터를 늘릴지 줄일지, 총공 문법을 어떻게 짤지가 데이터로 정해집니다.

## 4. 투표 깔때기 계측 3종 (기존 미구현 항목 · 재확인)

아레나 개편에 내장하기로 되어 있던 항목입니다. 대관 계측과 함께 확인 부탁드립니다.

| 이벤트 | 시점 |
|---|---|
| 대회 진입 | 대진표 생성 직후 |
| 첫 투표 | 1회차 선택 완료 |
| 완주 | 결승 픽 완료 |

이 3종이 있어야 **어디서 이탈하는지**를 볼 수 있습니다.
"들어왔는데 첫 투표를 안 함"과 "8강까지 가서 그만둠"은 완전히 다른 문제이고, 대응도 다릅니다.
