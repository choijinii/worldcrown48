## 3. 런칭 전 자동화를 하지 않는 이유

정정: **X는 자동 게시 자체를 금지하지 않습니다.** 규칙이 금지하는 것은 스팸과 플랫폼 조작입니다. 예약 게시는 위반이 아닙니다.

실제 근거는 셋입니다.

| 근거 | 확실성 |
|---|---|
| **투자 대비 효과가 안 맞는다.** 개발자 계정 신청·OAuth 인증·종량제 결제 등록·오류 대응에 드는 시간이, 아끼는 시간(하루 5분)보다 큽니다 | 확실 |
| **신규 계정이 낯선 도메인 링크를 반복 게시하면 도달이 억제될 수 있다.** 다만 X가 기준을 공개하지 않아 **정도는 알 수 없습니다** | 부분 확인 |
| **초기 계정 성장은 대화에서 나온다.** 답글·인용·팔로우는 자동 게시로 대체되지 않습니다 | 판단 |

비용은 근거가 아닙니다. 하루 3건 × 40일 ≈ $24로 부담이 없습니다.

## 4. 자동화 단계 계획

| 단계 | 기간 | 방식 | 내용 |
|---|---|---|---|
| **0단계** | D-38 ~ D-1<br>(8/31~10/7) | 전면 수동 | 큐 파일에서 복사·붙여넣기. 대화 중심 운영 |
| **1단계** | D-Day ~ D+3<br>(10/8~10/11) | 전면 수동 · 사람 상주 | **총공 기간. 자동화 일절 금지.** 실시간 반응·오류 대응이 전부 사람 판단 |
| **2단계** | D+4 ~ D+14<br>(10/12~10/22) | 반자동 | 시스템이 **초안을 큐에 쌓고**, 사람이 확인 후 발행. 문안 품질과 데이터 정확도를 이 구간에서 검증 |
| **3단계** | D+15 ~<br>(10/23~) | 자동 발행 | 검증된 유형만 자동 발행으로 전환 |

### 4-1. 1단계에서 자동화를 금지하는 이유

총공 3일은 전체 캠페인의 성패가 갈리는 구간입니다.
이 시기에 자동 게시가 잘못된 숫자를 내보내면 — 예를 들어 아직 반영 안 된 순위를 발표하면 — **정정할 시간이 없고, '인용되는 출처'라는 정체성이 첫날 무너집니다.**
자동화의 값은 꾸준함인데, 이 3일에 필요한 건 꾸준함이 아니라 판단입니다.

### 4-2. 3단계 자동 발행 대상

| 유형 | 주기 | 조건 |
|---|---|---|
| 일일 랭킹 | 매일 1회 고정 시각 | 4종 대회 1~3위와 전일 대비 변동 |
| 순위 역전 | 발생 시 | 1위 교체가 확정 집계된 경우에만 |
| 마일스톤 | 도달 시 | 누적 투표 수 단위 돌파 |

**공통 규칙**
- 우리 데이터만 사용. 외부 사실·커뮤니티 여론 인용 금지
- 집계가 확정된 값만. 진행 중 수치 금지
- 발행 실패 시 재시도하지 않고 큐에 남긴다 (중복 게시 방지)

### 4-3. 3단계 착수 전 확인

- 계정이 최소 2~3주 정상 운영됐는가
- 2단계에서 만든 초안 중 사람이 손대지 않고 나갈 수 있던 비율이 충분한가
- X API 가격 정책 재확인 (2026년에만 두 차례 변경됨)

### 5-2. `@allkppo` 제외 사유

allkpop은 과거 아티스트 사생활 사진 무단 게재, 정치 콘텐츠 공유 등으로 팬덤 내 평판 논란이 있었습니다.
우리 목표가 '인용되는 출처'인 이상, **첫 노출 창구로는 위험이 이득보다 큽니다.**
런칭 후 우리 인지도가 자리 잡은 뒤에는 재검토 가능합니다.

### 5-3. 팔로워 규모

**어느 계정도 확인하지 못했습니다.** X 계정 페이지가 로그인 뒤에 있어 검색 결과에 소개문만 노출됩니다.
계정 하나를 X에서 직접 열면 20초면 확인됩니다.

### 5-4. 명단 채우는 방법 (대표님 · 30분)

1. X 검색창에 영어로 입력 — `kpop chart` / `kpop comeback` / `kpop vote` / `kpop news` / `kpop awards`
2. 결과에서 **'사용자(People)' 탭**으로 이동
3. 쓸 만한 계정을 찾으면 그 계정의 **팔로잉 목록**을 봅니다. 같은 성격의 계정이 몰려 있습니다
4. 거르는 기준
   - 최근 7일 안에 게시물이 있는가
   - 특정 그룹만 다루지 않는가 (다루면 팬베이스이지 정보 계정이 아님)
   - 소개문에 문의 경로(메일·DM 개방)가 있는가
5. 아래 열로 기록 — `계정 / 성격 / 언어 / 팔로워 / 최근활동일 / 문의경로 / 확인일자`
