## 2. 오늘 회신문 §3의 정정 — `match_session_id`

제가 드린 설계는 **"판 = (사람 × 대회) 1:1"** 이라는 전제 위에 있었습니다. v2.0에서는 한 사람이 **같은 대회를 하루 5판**까지 돌 수 있으므로, `hash(사용자ID + 대회ID)`는 5판이 **모두 같은 값**이 되어 판 구분이 무너집니다.

**정정안**: 식별값에 **회차(몇 판째인지)** 를 포함합니다.

- `match_session_id = hash(내부 사용자ID + 대회ID + 회차) 앞 16자`
- 결정적 해시라는 장점(저장소 불필요, 폰에서 완주 → PC에서 공유해도 같은 값)은 **그대로 유지**됩니다.
- 요청하신 분석 3종(①연출→공유율 ②대회별 전환 ③몇 번째 판부터 의욕 하락)은 **오히려 더 정확해집니다** — 종전엔 이벤트 시각 순서로 판 서수를 "복원"해야 했지만, 이제 회차가 값 안에 들어 있습니다.
- 같은 사람이 하루 A대회 5판이면 값 5개, 4대회 전부 돌면 값 20개.

## 3. 마케팅 쪽에서 확인·수정이 필요한 것

1. **"하루 5번" 표현** — `대관연출_인계_Crown_Ceremony_2026-08-31.md`:33의 "하루 5번 하는 구조"는 뜻은 맞으나, 정확히는 **"한 대회를 하루 5판"** 입니다. 캠페인 카피에 쓰실 때는 "**하루 5판**" 또는 "**한 대회를 하루 다섯 번**"으로 부탁드립니다.

3. **소구점 추가 가능** — "돌릴 때마다 대진이 새로 섞여 다른 챔피언이 나온다"는 v2.0에서 처음 성립하는 사실입니다. 재방문 유도 카피의 재료가 됩니다.
