4. **`first_vote` + `match_session_id` 회차** (09-03 서신 건) → PR 3

## 판정 지표 재정의 (v1.2 표 참조)
- 완주율·공유율은 **`is_guest`로 나눠서** 봅니다. 게스트 공유가 열리면 섞였을 때 회원 공유율이 부풀려 보입니다.
- 게스트 전환율 = `guest_signin_convert` ÷ (`guest_limit_view` + `share_locked_view`), trigger_point별로 분해.
- 데이터 정합성 보정계수(GA ÷ Firestore 완주)는 그대로 유효하고, PR 2부터 Firestore 기록에도 `isGuest`가 붙어 게스트/회원 대조가 정확해집니다.
