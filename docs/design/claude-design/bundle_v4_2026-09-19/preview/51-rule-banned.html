Banned patterns · the recurring errors
DON'T

"AI GENERATED" badges

Permanently retired. Use ✦ AI-Report only — and only as the footer of a news article (12px gold mono). Never on cards, banners, or boxes.

DON'T

Match / Round deadlines

No ENDS IN 03:14:22 timer anywhere. Match and Round have no deadline. Only Tournament Deadline exists.

DON'T

Vote Rate on Match VS

Showing live % during a Match creates bandwagon bias. Vote Rate appears on the Ranking screen only.

DON'T

LIVE pill — anywhere

WC48 does not live-stream. A LIVE pill implies simultaneous multi-participant viewing, which the product never delivers. Permanently retired from TournamentCard, Arena, GNB, and every other surface.

DON'T

Odds · prediction · betting

WC48 is fan-choice. "Crown odds", "projected winner", "favorite to win" — all off-brand.

DON'T

Vote Count absolute integers

Never display raw vote counts in UI. Stored internally only. Surfaced as Vote Rate (%) on the Ranking screen.

DON'T

"In Progress" status

Not a valid Tournament status. The five values are draft / published / active / closed / completed.

DON'T

"FIFA" / "Official" text

Trademark territory. Use Football, International as neutral alternatives.
