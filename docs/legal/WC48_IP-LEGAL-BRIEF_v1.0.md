## §1. 핵심 결론 (대표 확정 해석 포함)

1. **법 집행은 선택적이다** — 소송·제재는 거의 전부 "명백한 상업적 도용"(비공식 굿즈, 무단 화보집, 얼굴 광고)에 집중된다. 보도·팬 활동·홍보성 사용은 사실상 묵인된다. (대표 해석, 판례로 확인됨)
2. **숨피(Soompi)는 저작권을 "피해가는" 게 아니라 3층 리스크 관리 스택 위에서 운영한다** (§3).
3. **CC 라이선스는 저작권만 해결한다** — 초상권·퍼블리시티권은 별개로 남는다. 위키미디어 커먼즈도 유명인 사진에 "Personality rights" 경고를 붙인다.
4. **MVP2(유저 생성 토너먼트)부터는 WC48도 safe harbor(면책) 구조를 쓸 수 있다** — 조건은 신고·삭제 채널 구축 (§5).

## §2. 법률 지형 요약

| 법률/제도 | 내용 | WC48 관련성 |
|---|---|---|
| 미국 DMCA (1998) | 통지·삭제(notice-and-takedown): 권리자 이의 제기 시 신속 삭제하면 플랫폼 면책. **이용자 업로드 콘텐츠에 적용** | MVP2 유저 생성 콘텐츠의 방어선 |
| 한국 저작권법 §102~103 | DMCA와 유사한 온라인서비스제공자 책임 제한 + 복제·전송 중단 절차 | 동일 |
| 정보통신망법 임시조치 | 초상권 등 권리침해 신고 시 30일 임시 차단 | 신고 채널 설계 시 반영 |
| 부정경쟁방지법 개정 (2022-06 시행) | 유명인의 초상·성명 등 식별표지 무단 **영리** 사용 = 부정경쟁행위 (사실상 퍼블리시티권 입법) | **WC48 최대 리스크 축** |
| 2026-03 첫 시정명령 | 아이돌 초상 무단 비공식 굿즈 제재 — 집행 개시 신호 | 수익화 설계 시 경계선 참고 |
| 저작권법 시사보도·인용 예외 (§26·§28) + 미국 fair use | 보도·비평 목적 사용 보호 | 숨피의 방패. **WC48은 사용 불가** (보도 매체 아님) |

## §3. 숨피 사례 분석 — 3층 리스크 관리 스택

- 회사 구조: 1998 팬사이트 → 2015 Viki 인수(<$10M) → Viki는 일본 라쿠텐 소유. **운영 실체는 미국 회사**(Viki Inc., 캘리포니아).
- "외국 회사라 한국법 적용이 어렵다"는 부차적 요인. 본질은 아래 스택:

| 층 | 장치 | 커버 범위 |
|---|---|---|
| 1층 | 낮은 리스크 소스 — 소속사 보도자료(묵시적 이용허락)·공식 SNS 임베드·보도 프레임(fair use) | 자체 제작 기사 |
| 2층 | DMCA 통지·삭제 신속 대응 (숨피 정책이 강조하는 유일한 법적 장치) | 분쟁 발생 시 확전 차단 |
| 3층 | 권리자의 고소 유인 부재 — 숨피 = 무료 글로벌 홍보 채널 (공생) | 전체 |

- ※ 주의: DMCA safe harbor는 원칙적으로 **이용자 업로드** 콘텐츠 보호 장치. 숨피 자체 기사에는 1층·3층이 실질 방어선.

## §4. WC48에 적용 — 숨피와의 결정적 차이

```
숨피: 보도 매체 → 보도 예외·fair use·프레스킷 사용 가능
WC48: 상업 서비스, 유명인 얼굴이 콘텐츠 그 자체 → 위 방패 전부 사용 불가
```

- 1차 런칭 시드 콘텐츠(운영자 제작 = K1~C4 트래커) → **면책 불가**. Level 1(CC)/Level 2(공식 SNS 수동승인) 정책 유지 필수.
- CC 이미지라도 퍼블리시티권 쟁점은 남는다. 다만 팬 투표는 굿즈·광고 같은 직접 영리 도용과 결이 다르고, PIKU 등 국내 동종 서비스가 같은 구조로 공개 운영 중 (묵인 영역).
- **경계선 원칙: 특정 인물의 초상을 "직접 돈 버는 지점"(광고 크리에이티브, 유료 상품, 굿즈)에 두지 않는다.** 서비스 이용료·일반 광고 지면과 콘텐츠는 분리.

## §5. 실행 항목 (결정 게이트 포함)

| # | 항목 | 시점 | 상태 |
|---|---|---|---|
| 1 | Policy Hub(E-1)에 **권리침해 신고 채널 + 삭제 프로세스** 추가 — DMCA·저작권법 §103·임시조치 대응 | MVP2 유저 생성 기능 오픈 **전** (필수 선행) | 대기 |
| 2 | 퍼블리시티권 법무 검토 **결정 게이트** — 수익화(광고·프리미엄) 켜기 전 필수 | 수익화 설계 전 | 게이트 등록 |
| 3 | 시드 콘텐츠는 Level 1(CC)/Level 2(공식 SNS 수동승인) 정책 유지, 미성년자 절대 금지(만 19 기준) | 상시 | 운영 중 |
| 4 | 소속사 대상 커뮤니케이션 채널 준비 (요청 시 즉시 삭제 + 제휴 전환 여지) | 런칭 후 | 대기 |
