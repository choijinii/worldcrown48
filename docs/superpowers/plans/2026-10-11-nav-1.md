# NAV-1 메뉴바·서랍 개편 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (인라인 실행). Steps use checkbox (`- [ ]`) syntax.

**Goal:** 팬이 어디서든 같은 메뉴(The Pitch · The Arena · Record Room · Newsroom · Locker Room)로 움직이고, 메뉴바 펼침 메뉴로 하위 화면에 바로 가며, `/records`와 크라운 카드에서 어느 대회의 차트든 찾아가게 한다.

**Architecture:** 메뉴 구조는 순수 모듈 `lib/layout/navMap.ts` 한 곳(키 기반 · 3언어 라벨 · The Lab 스위치)이 정하고, `Navbar`(메뉴바 + 펼침) · `NavDrawer`(서랍)는 그것을 그리기만 한다. `/records`는 서버에서 공개 대회·차트 캐시를 읽고 순수 함수 `lib/records/chartList.ts`가 진행 중/끝난 대회로 나눈다. `ModuleNav`는 지우고 크라운 카드에 "차트 보기" 링크를 둔다.

**Tech Stack:** Next.js 14 App Router · TypeScript · CSS(토큰만) · Firebase 클라이언트 SDK · vitest(node) · Playwright.

**Spec:** `outputs/PROMPT_ClaudeCode_NAV-1_v1.2_2026-10-11.md` (워크트리로 옮김 · 커밋하지 않음) + 원장 D-18·D-19(+09-21·09-22)·D-20·D-21·D-22·D-34·D-37·D-40·D-44 + 정본 `docs/design/claude-design/Arena_Match_Stage_v3_32boards_2026-10-10.dc.html` (+ `export_v3_2026-10-10/components/GNB/GNB.jsx`).

## Global Constraints

- 화면 문구: 승인된 것만. 게이트 5 미승인 문구는 커밋 전 대표 되번역 승인 — 승인 전 커밋에는 `MARKETING_PENDING` 표식.
