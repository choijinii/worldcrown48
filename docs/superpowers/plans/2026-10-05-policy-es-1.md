# POLICY-ES-1 동의 층·정책 문서 스페인어판 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 화면 언어가 es일 때 동의 바·설정 창·정책 문서 4개를 스페인어로 읽게 한다. ko·en 화면은 한 글자도 바꾸지 않는다.

**Architecture:** 동의 바는 `useI18n().lang === "es"`일 때만 한국어 자리를 스페인어로 바꾼다(ko·en 출력은 지금 그대로). 설정 창은 이미 `data-ml={lang}` + CSS 숨김 구조라 `.ml-es` 줄을 더하고 es 숨김 규칙을 추가한다. 정책 페이지는 이미 "두 언어를 DOM에 함께 그리고 CSS로 숨김" 구조라 세 번째 언어(`doc-es`)를 같은 방식으로 더한다. 사이트맵은 `POLICY_LANGS`에 es를 넣는다.

**Tech Stack:** Next.js 14 · gray-matter + react-markdown · Vitest(node, `react-dom/server` 렌더) · Playwright(CI)

**Spec:** `outputs/PROMPT_ClaudeCode_POLICY-ES-1_v1.0_2026-10-05.md` (원장 > 지시서)

## Global Constraints

- R1 ko·en 화면의 동의 바·설정 창 글자 불변 — `cookieBannerCopy.test.ts` 그대로 green.
- R3 스페인어는 한국어 원문에서 번역, 영어판은 대조만. 뜻 차이는 목록으로 보고(영어판 수정 안 함).
- R4 `CURRENT_POLICY_VERSION = "1.0"` 불변. 문서 프론트매터 `version` 1.0 → 1.1 · `lastUpdated` 2026-10-05는 조항 추가와 함께.
- R5 중립 국제 스페인어 · 정책 문서 usted · 버튼·라벨은 짧게 · 공식 용어(Tournament 등)는 영어 그대로 · 팬 = fans.
- R6 토큰만 · R7 무대·배너·COOKIE-1 여백/가로 미룸 유지.
- 승인 게이트: 동의 바·설정 창·정책 페이지 화면 문구 + "원문 우선" 조항 3언어는 **커밋 전 한국어 되번역 표로 승인**.
- `firestore.rules` 무변경 · 배포·병합 금지.
