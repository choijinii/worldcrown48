## 핵심 비전

48명의 후보를 1:1 녹아웃 방식으로 투표해 최후의 1인을 가리는 글로벌 팬덤 토너먼트 플랫폼.
2026 FIFA 북중미 월드컵을 기점으로 전 세계 팬덤 데이터를 수집하고, Crown Card 바이럴로 성장한다.

---

## 서비스 정체성 (절대 불변)

```
월크48 = 팬이 좋아하는 Candidate를 투표하는 서비스 (이상형 월드컵 방식)

투표의 의미:
  "나는 이 후보가 더 좋다" (팬의 선호 표현)
  → 현실 경기 결과 예측 아님
  → 내기/베팅 아님
  → 객관적 순위 평가 아님

절대 금지 설계:
  - 우승자 예측 게임 기능
  - 스포츠 베팅 / 내기 연동
  - 실제 경기 결과와 연동
  - 외부 일정(FIFA 등)에 자동 종속
```

## 도메인 용어 (Glossary)

이 프로젝트의 모든 코드, 이슈, 문서에서는 아래 용어를 정확히 사용한다. 동의어로 대체하지 않는다.

### 핵심 개념

| 용어 | 정의 | 사용 금지 동의어 |
|---|---|---|
| **Tournament (대진)** | 48명의 후보가 참여하는 하나의 토너먼트 인스턴스 | 투표, 이벤트, 경쟁 |
| **Candidate (후보)** | 토너먼트에 참가하는 48명 중 1인 | 선수, 참가자, 항목 |
| **Match (매치)** | 라운드 내의 단일 1:1 대결 | 배틀, 경기, 대결 |
| **Round (라운드)** | 48강·24강·12강·6강·Final의 각 단계 | 스테이지, 레벨 |
| **Crown Card** | 투표 결과를 담은 공유 가능한 시각적 카드 이미지 | 결과 카드, 공유 이미지 |
| **Vote (투표)** | 매치에서 한 후보를 선택하는 단일 행위 | 선택, 클릭, 픽 |
| **Pitch (더 피치)** | 메인 홈·랜딩 페이지. 트렌딩 대진 목록 표시 | 홈, 메인, 랜딩 |
| **Lab (더 랩)** | 관리자가 새 대진을 생성하는 도메인 (MVP 기간 비공개) | 생성, 만들기 페이지 |
| **Arena (더 아레나)** | 1:1 투표가 진행되는 도메인 | 투표 페이지, 경기장 |
| **Locker Room (더 라커룸)** | 유저 프로필·투표 기록 도메인 | 마이페이지, 프로필 |
| **Policy Hub (폴리시 허브)** | 이용약관·정책·쿠키 동의 도메인 | 약관 페이지 |
| **Admin Dashboard (관리자 대시보드)** | System Admin 전용 운영 콘트롤 센터 (Domain 6) | 관리자 페이지 |
| **Crown (크라운)** | 최종 우승자 또는 우승 상태를 나타내는 개념 | 1등, 우승자 |
| **Node (노드)** | The Lab에서 후보 48개 슬롯 중 하나 | 칸, 슬롯, 셀 |
| **Trend Score** | 실시간 투표 활동 기반 대진 인기도 점수 | 인기도, 랭킹 점수 |
| **AI 채우기** | Claude API로 48명 후보를 자동 추천하는 기능 | ~~AI 채유기~~ (오타 수정) |

### 제재 시스템 용어

| 용어 | 정의 |
|---|---|
| **Content Warning (1단계)** | 경미한 위반 시 콘텐츠 삭제 + 경고 |
| **Activity Restriction (2단계)** | 7일 댓글·투표 생성 정지 |
| **Account Suspension (3단계)** | 30일 계정 전체 정지 |

| **Legal Action (5단계)** | 수사기관 신고 + 민·형사 소송 |

## 투표 정책 (v4.5 확정)

```
✅ 확정 규칙:
  - 대진별 1일 5회: Voter 1계정 기준 동일 Tournament에서 하루 최대 5개 Match 투표 가능
  - 자정 리셋: 매일 자정(KST 00:00 기준) 카운트 초기화
  - 복수 Tournament: 각 Tournament별 독립 5회 카운트 적용
  - 계정 필수: Google / Apple 소셜 로그인 필수 (익명 투표 없음)

❌ v4.5에서 완전 삭제된 규정:
  - "같은 Match 하루 1번" 규정
    삭제 이유: 랜덤 매치 알고리즘에서 동일 Match가 하루 최대 4회까지
    재출현하는 것은 필연적이며 기술적으로 막을 수 없음.
    정상 투표를 방해하는 불합리한 규정이었음.

랭킹 노출 정책:
  - Vote Count(절대 수치) 노출 금지
  - Vote Rate(득표율 %) + 1시간 캐시만 표시
```

## 핵심 불변 원칙

다음 원칙은 ADR(Architecture Decision Record) 없이 변경 불가. 변경이 필요하면 반드시 ADR 작성 후 결정.

1. **다크모드 전용** — 라이트모드 없음. 배경은 항상 `#05070A`.
2. **Pure Gold만 허용** — 포인트 컬러는 `#FFD700`만 사용. 형광 노랑, 형광 그린 절대 금지.
3. **한국적 요소 금지** — 태극 문양, 한옥 디자인, 붓 글씨체 사용 금지. 글로벌 MZ Sporty 럭셔리.
4. **AI 생성 표기 의무** — AI가 생성한 모든 콘텐츠에 "AI GENERATED" 배지 필수.
5. **FIFA 상표권 준수** — "FIFA", "Official" 표기 금지. 팬 기반 서비스임을 명시.
6. **초상권 보호** — 얼굴 이미지는 관리자가 수동으로 공개 출처 URL만 입력. 자동 수집 금지.
7. **모바일 앱 없음** — 웹 전용. Flutter 전환 계획 없음.
8. **React + Firebase 스택** — 스택 변경 시 ADR 필수.

## 사용자 흐름 핵심 패턴

**투표 → Crown Card → 공유 흐름 (바이럴 루프):**
```
방문 → The Pitch 대진 선택 → The Arena 1:1 투표 (비로그인 1회)
→ Crown Card 자동 생성·미리보기 (비로그인 가능)
→ 공유 버튼 클릭 → 구글 로그인 요청
→ 로그인 완료 → SNS 공유 (뉴스 링크 첨부)
```

이 흐름은 서비스의 핵심 바이럴 메커니즘이다. 로그인 요청 시점을 Crown Card 미리보기 이후로 유지한다.
