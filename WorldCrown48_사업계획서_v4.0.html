01 서비스 개요
Executive Summary

WorldCrown48은 2026 FIFA 북중미 월드컵을 겨냥한 글로벌 팬 투표 플랫폼입니다. 팬들이 48개국 국가대표팀(Contestant) 중 가장 좋아하는 팀을 1:1 토너먼트 방식으로 투표하고, 그 결과를 AI가 분석해 뉴스 콘텐츠로 자동 생성하는 독창적인 서비스입니다.

🎯 핵심 가치 제안

  • • 이상형 월드컵 방식의 직관적 팬 투표 경험 (48강 → 24강 → … → Champion)
  • • 실제 팬 투표 데이터 기반 AI 뉴스 생성 — Fan Intelligence (독점 콘텐츠)
  • • Crown Card: 팬 개인화 결과 이미지 → SNS 바이럴 확산 엔진
  • • 글로벌 다국어 지원 (ko / en / es) + Cloudflare CDN 전 세계 빠른 접속
항목내용
서비스 컨셉팬이 투표하고 AI가 보도하는 글로벌 축구 팬덤 허브

▶ Voter(팬) 투표 흐름

48강 Tournament 진행 방식

① 48강 (24 Match) → ② 24강 (12 Match) → ③ 12강 (6 Match)

④ 6강 (3 Match)   → ⑤ 결승 (1 Match)  → ⑥ Champion 확정


  • • Match는 Voter에게 순서대로 1:1로 제시 (동시 진행 아님)
  • • 라운드 전환: Voter가 마지막 Match 완료 시 advanceRound() 자동 실행
  • • Tournament Deadline만 존재 — Round Deadline 없음
  • • Champion 확정 → Crown Card 자동 생성 → SNS 공유 유도
04핵심 차별점 & 경쟁 우위
Key Differentiators

WorldCrown48의 3대 핵심 차별점은 Fan Intelligence, Crown Card, 그리고 독점 팬 데이터입니다.

🏆 차별점 1 — Fan Intelligence (AI 뉴스)

  • • 전 세계 어느 미디어도 보유하지 못한 "실시간 팬 투표 데이터" 기반 AI 뉴스
  • • "AI가 썼다"가 아니라 "팬 데이터가 근거다" — 검증 가능한 팩트 기반 신뢰
  • • EU AI Act Art.50 준수 AI-Report 표기 + 관리자 검수 이중 안전장치

👑 차별점 2 — Crown Card 바이럴 엔진

  • • Champion 결정 후 개인화된 결과 이미지(Crown Card) 자동 생성
  • • "내가 직접 뽑은 우승자" 스토리텔링 → SNS 자발적 공유 유도
  • • 외부 광고 없이 사용자 자신이 홍보 채널이 됨 (바이럴 CAC ≈ 0)

📊 차별점 3 — 독점 팬 데이터 자산

  • • 축적되는 팬 투표 데이터 = 누구도 복제 불가한 독점 자산
  • • 데이터 → Fan Intelligence → 미디어 파트너십 → B2B SaaS (MVP 3)
  • • 경쟁자가 늦게 따라올수록 데이터 격차는 더 벌어짐
05 ★ Fan Intelligence — AI 뉴스 전략 신규
실시간 팬 투표 데이터 기반 AI 뉴스 생성 시스템

Fan Intelligence는 WorldCrown48 플랫폼에서 수집된 실제 팬 투표 데이터를 기반으로 AI(Claude API)가 작성하고 관리자가 검토·승인한 뉴스 보도 포맷입니다. "AI가 썼다"는 사실보다 "팬 데이터가 근거"라는 사실이 앞섭니다. 데이터가 주인공, AI는 도구.
